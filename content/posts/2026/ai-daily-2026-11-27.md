## FinCEN 遭未授權存取，資訊長的遊戲持續更新

美國財政部旗下金融犯罪執法局（FinCEN）負責接收銀行對可疑資金的申報。該局在週二晚間表示，有人「未經授權存取」其「有限範圍」的系統，因此將部分系統下線。批次申報功能此前已故障數天，部分申報者獲准延至 12 月 30 日補交。

財政部資訊長 Sam Corcos 當晚也相當忙碌。[原報導指出](https://www.404media.co/sam-corcos-legatum-treasury-cio-is-vibe-coding-a-civilization-clone-during-treasury-department-hack/)，他上個週末開始製作、使用 Claude 與 Codex 開發的《文明帝國》仿作 Legatum，在週二晚間至週三早晨之間有[超過 30 次更新](https://github.com/samcorcos/legatum/commits/master)。阿茲特克文明有了專屬音樂，埃及則加入戰車弓箭手；他告訴 Claude，原因是「他們目前的特殊單位很遜」。

隨後，有人在遊戲的 [GitHub 問題回報](https://github.com/samcorcos/legatum/issues/147)寫道：「財政部資訊長忙著 vibe coding，沒有做好自己的工作。」回報者列出的預期結果是：「FinCEN 能正常運作。」Corcos 將該問題以「不在計畫內」結案。不到兩小時，遊戲就加入了會自動關閉離題問題的機器人。

財政部尚未說明資訊長在這次入侵事件中做了哪些處置。FinCEN 表示，正「積極努力」恢復系統。至於 Legatum 的城牆，如今已有九個等級。這是原文並置兩件事的評論，並非已證實遊戲開發導致資安事件或妨礙應變。

## AI 省下的時間，只有 1% 的使用案例讓員工多休息

Anthropic 發布一份[企業如何使用 AI 的研究](https://www.anthropic.com/research/working-with-ai)，訪談其 58 家美國企業客戶中的 66 人，涵蓋百年企業、律師事務所、避險基金、牙醫、卡車運輸公司與 AI 原生新創。主要發現是：AI 多半協助企業增加產出，直接由 AI 導致的裁員則很少見。

最鮮明的數字，是收益由誰取得。在受訪者明確說明是否產生效益及其流向的 AI 使用案例中，55% 增加了企業產出，19% 降低企業成本，只有 1% 讓員工獲得更多休息時間。這裡的 1% 是使用案例占比，並不是員工只拿到全部節省工時的 1%。研究也提醒，這批客戶並非隨機或具系統代表性的樣本，效益多來自受訪者的質性描述。

即使這 1%，仍讓部分主管介意。一名主管說，員工會隱藏使用 AI 帶來的效率提升，「因為他們想拿每週那 10 小時去遛狗」。與此同時，約三分之二受訪企業因 AI 而減少招募。一名工程主管說：「我們靠購買 token，而不是雇人，增加了很多產能。」[原文引用的報導](https://the-decoder.com/anthropic-study-shows-the-hardest-part-of-adopting-ai-at-work-has-little-to-do-with-learning-the-tools/)也討論了員工抗拒與組織調整。

販售這些 token 的 Anthropic，在研究結尾呼籲雇主與員工分享收益。原文的觀察是：目前企業拿走新增產出，token 取代下一個招募名額，而替自己省下一小時遛狗的員工，還得把這件事藏起來。

## Tesla 股東，可能迎來最後一次能否決馬斯克的投票

據原文[先前報導](https://aisecret.us/spacex-and-tesla-negotiate-without-musk/)，SpaceX 與 Tesla 正洽談一筆約 3.5 兆美元的全股票合併交易，最快可能在 12 月宣布。這仍是洽談中的交易，並非已完成合併。Elon Musk 同時領導兩家公司，但持股權利不同：在 SpaceX，超級投票權股份讓他掌握約 84% 表決權；Tesla 則一股一票，他掌握約五分之一。

這個差距正是交易可能改變之處。如果由 SpaceX 吸收 Tesla，馬斯克的表決權可能合計超過合併後公司的半數。[原文引述 HSBC 分析師](https://aisecret.us/hsbc-prices-a-spacex-bid-for-tesla/)，將控制權稱為「關鍵動機」。

馬斯克曾表明自己認為多少控制權才合適。他在 [2024 年的貼文](https://x.com/elonmusk/status/1746999488252703098)寫道：「如果沒有約 25% 的投票控制權，我對把 Tesla 發展成 AI 與機器人領導者感到不自在。要足以發揮影響力，但又不至於無法被推翻。」

Tesla 股東仍能決定交易是否通過。原文指出，交易需要超過全部 Tesla 股份的半數同意，因此棄權的效果等同反對。若通過，這可能是馬斯克最後一次可能輸掉的投票。他仍會很有影響力；要推翻他的決定，則是另一回事。這是原文對潛在控制權結構的判斷。

## OpenAI 延攬打造 Claude Code 的人

三名參與打造 Claude Code 的成員，在 Anthropic 首次公開募股前幾週離職，而三人如今可能都已轉往 OpenAI。曾負責 Claude Code 產品的 Cat Wu，[將加入 OpenAI](https://aisecret.us/cat-wu-leaves-claude-code-for-openai/)，領導 Core Products 的產品管理，範圍包括 ChatGPT、Codex 與 API。

[一個追蹤人員異動的匿名帳號聲稱](https://officechai.com/ai/anthropics-thariq-shihipar-who-was-the-face-of-claude-code-on-x-has-reportedly-joined-openai/)，打造桌面應用程式的 Anthony Morris 與工程師 Thariq Shihipar 也跟著轉職。原文將這兩人的消息列為尚未獲本人或 OpenAI 證實。補充核對：Thariq 已在[本人公開貼文](https://x.com/trq212/status/2125675533761671405)宣布加入 OpenAI，頁面顯示台北時間 11 月 26 日凌晨 3:38（美東時間 11 月 25 日下午）；Anthony Morris 的轉職消息仍未獲證實，不能將三人全數加入視為已確認消息。

這些人事安排符合 OpenAI 的方向。Anthropic 先把 Claude Code 從終端機帶到桌面應用程式，再推出面向非程式設計者的 Cowork；OpenAI 正讓 Codex 與 ChatGPT Work 走向同一條路。Wu 的第一篇貼文承諾打造讓使用者「保有控制權」的代理，這也是她過去兩年在 Anthropic 所做的工作。

原文認為，離職對他們的既得權益影響有限。Anthropic 選擇權持有人在 9 月共有約 1,190 億美元帳面收益，其中約 730 億美元已歸屬；這類已歸屬權益通常能在離職後保留。這是全體持有人的數字，並非上述三人的個人收益。而 OpenAI [也表示將上市](https://aisecret.us/altman-says-openai-will-go-public/)。

Codex 原是 OpenAI 對 Claude Code 的回應。如今，依原文的比喻，它開始聘用當初寫出這道題目的人。
