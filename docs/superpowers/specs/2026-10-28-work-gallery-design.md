# Work 與 CV 內容拆分草稿

狀態：使用者已於 2026-10-28 核准，依此實作與發布。

## 目的

將 ChatGPT 個人頁的完整資訊依用途拆分至 `/work` 與雙語 CV。保留精選作品、全部五項統計、Token 活動圖、熱門外掛與深入分析，讓訪客無須登入即可閱讀。

使用者已指定保留整個個人頁的資訊價值，並要求重現統計與圖表的 UI。沿用現有網站與靜態發布流程。

## 方案

採用站內作品介紹與外部體驗連結。嵌入整個 ChatGPT 個人頁仍會遇到登入限制；完整搬移五個應用程式則超出這次內容整理範圍。

以下內容編排已經使用者核准。

## UI 重現

- 統計區保留五欄橫帶、圓角外框、欄間細分隔線、數值與標籤的上下層級。
- Token 活動保留密集方格、藍色強度、月份刻度與每日、每週、累計切換。三種檢視均已在來源頁操作確認。
- 深入分析保留左側標籤與右側數值對齊；熱門外掛保留圖示列與可讀名稱。
- 以站內元件重現可讀文字與可操作 UI，不用一張整頁截圖取代頁面內容。原頁截圖作為視覺核對依據。
- 活動圖已從來源 DOM 取得各模式實際色階，依原序重現；沒有逐日 Token 數值，不補造數值或提供推算 tooltip。
- 小螢幕調整排列，仍保留所有欄位；雙語 CV 的單位與翻譯維持一致。
- 自介、編輯、分享等帳號操作不屬於個人資訊內容，不複製 ChatGPT 的帳號管理功能。

## 版面與導覽

- 保留 ChatGPT 個人頁的精選順序，使用現有 Card、Badge 與 Button。
- 桌面沿用來源三欄，中型螢幕兩欄、手機單欄。每項作品有畫面、名稱、分類、簡介與體驗入口。
- 畫面存為網站自己的靜態資產，避免引用會到期的 Sites 截圖網址。
- 不使用 iframe，不在載入作品頁時自動載入外部應用程式。
- 桌面與手機導覽、首頁及 About 的作品入口回到 `/work`。
- 首頁保留簡短入口，不重新列出職涯卡片。
- GJ、Nidin 與 JurisLM 詳細案例網址保留；完整職涯在 CV 閱讀。
- Token 活動、完整統計、熱門外掛與深入分析依對照表分配，不省略原頁資訊。

## 來源與驗證範圍

2026-10-28 讀取使用者已登入的 ChatGPT 個人頁，確認五項精選作品與直接網址。Sites 清單核對名稱、描述及發布網址。四張作品預覽保留原頁影像；Block Out! 原預覽被安裝提示遮擋，改用公開遊戲的完整棋盤實拍。外掛圖示為原頁實際畫面。

## 驗收

- 未登入訪客可閱讀 `/work` 所有作品文案及靜態畫面。
- 五個作品名稱、直接網址與畫面逐項核對。
- 五項統計、四項深入分析、四個熱門外掛與三種活動檢視逐項核對；不得遺漏或編造資料。
- CV 與 Work 的每項數據均有來源與擷取日期，且互相提供區塊連結。
- 桌面與手機的站內作品入口一致。
- Ochre Chess 登入限制與 ASCII Sharks 署名清楚可見。
- DefectHunter AI 不描述為通過工業檢測驗證的正式產品。
- 型別、lint、測試、建置、審查、CI 及發布後實際頁面驗證完成後才宣稱發布。
